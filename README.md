# Slot Machine - Mini Juego Web

Este proyecto es un ejercicio práctico del Certificado Profesional N3 en Desarrollo de Aplicaciones con Tecnología Web. Se trata de una máquina tragaperras (slot machine) desarrollada con tecnologías web básicas: **HTML**, **CSS** y **JavaScript**.

## Características

- Interfaz visual con frutas animadas
- Sistema de vidas: pierdes o ganas según el resultado
- Lógica para detectar combinaciones ganadoras
- Diseño responsive y animaciones sencillas

## Cómo jugar

1. Pulsa el botón para girar los rodillos.
2. Si aparecen tres frutas iguales, ganas una vida.
3. Si no hay coincidencias, pierdes una vida.
4. El juego termina cuando se agotan las vidas.

## Tecnologías utilizadas

- HTML5
- CSS3 (animaciones incluidas)
- JavaScript (DOM, lógica de juego)
